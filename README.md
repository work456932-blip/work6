# GSD-VQ

Anonymous code for *How Many Is Many Here? Generalized Stochastic Dominance for Context-Aware Visual Quantifier Grounding*.

GSD-VQ grounds vague visual quantifiers by comparing an observed-count distribution with a scene-conditioned expected-count proxy using generalized stochastic dominance. Signed dominance and CDF-incomparability statistics are mapped to five VAQUUM quantifiers through a shape-constrained decoder, capturing both relational direction and uncertainty. The framework supports context-aware quantity interpretation and evaluation against human quantifier ratings and expected-count judgments.
